# Security Policy

## Reporting a vulnerability

Use **GitHub Security Advisories** on this repository (Security → Advisories →
New draft advisory / Report a vulnerability). Include steps to reproduce,
affected versions, and impact.

Do **not** open a public issue for undisclosed vulnerabilities.

We aim to acknowledge reports within a few business days and to ship a fix or
mitigation for confirmed issues in the next release when practical.

## Scope

This policy covers this app: the React frontend in `src/` and the Rust
backend in `backend/`.

Issues in the shared template belong upstream:

- [stevederico/skateboard](https://github.com/stevederico/skateboard) (boilerplate)
- [@stevederico/skateboard-ui](https://github.com/stevederico/skateboard-ui) (UI shell)

## Supported versions

Only the latest release receives security fixes.
